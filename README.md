# Task 4 - Real-Time Communication App

Full-stack video conferencing and collaboration platform using React, Node.js, Express, Socket.io, WebRTC and MongoDB.

Features: JWT authentication, multi-user video/audio, screen sharing, real-time chat, collaborative whiteboard, file sharing, protected APIs and upload validation.

## Run
Backend: `cd server && npm install && cp .env.example .env && npm run dev`
Frontend: `cd client && npm install && npm run dev`

Requires MongoDB. For production WebRTC deployments, configure HTTPS and a TURN server.
